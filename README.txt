PyDesk
Windows 用の軽量な Python コードテスト

起動と実行
  PyDesk.exe をダブルクリックします。Windows 10 / 11 の x64 環境向けです。
  Python 3 が必要です。PATH の python.exe、次に Windows の py.exe -3 を探します。
  初回は整数を合計するコードと入力「3 1 4 1 5」が入っています。
  Ctrl+Enter を押すと、実行結果に 14 が表示されます。
  左のコードと右上の標準入力を書き換えて、同じ操作で何度でも試せます。

コードの編集
  Ctrl+F / Ctrl+H              検索 / 置換
  F3 / Shift+F3               次 / 前の一致
  Ctrl+D                      単語を選択。続けて押すと次の一致も選択
                              複数選択中の文字入力、貼り付け、削除は全箇所に反映
  Esc                         複数選択を解除
  Ctrl+/                      現在の行または選択行のコメントを切替
  Alt+↑ / Alt+↓               行または選択行を移動
  Alt+Shift+↑ / Alt+Shift+↓   行または選択行を複製
  Tab / Shift+Tab             4 スペースのインデント / インデント解除
  Ctrl+Space                  Python キーワード・組み込み名・文書内の単語から補完
  Ctrl+Z / Ctrl+Shift+Z       元に戻す / やり直す
  Ctrl+N / Ctrl+O / Ctrl+S    新規作成 / 開く / 保存
  Ctrl+Shift+S                名前を付けて保存
  F6 / Shift+F6               コード、標準入力、実行結果の間でフォーカスを移動

  if や for のブロックを始める行で Enter を押すと、次の行を 4 スペース深くします。
  入れ子や行末のコメントにも対応します。以降の本文では同じ深さを引き継ぎます。
  if / elif / for / while の行末では、コロンの入力前でも字下げします。
  Python のコードを実行するときは、ブロックを始めるコロンを入力してください。
  括弧や引用符を入力すると対応する閉じ記号を挿入します。
  範囲を選択して開き記号を入力すると、その範囲を記号で囲めます。
  エディタは Windows の RichEdit を使用します。補完は単語ベースです。

テストの実行
  Ctrl+Enter / F5             現在のコードと入力で実行
  「制限なしで実行」ボタン      今回だけ時間制限を外して実行
  Shift+F5                    実行中の Python と子プロセスを停止
  「実行」メニューで時間制限を 2 秒、10 秒、60 秒、制限なしから選べます。
  初期値は 10 秒です。通常の実行ボタンに現在の設定が表示されます。
  結果欄に標準出力と標準エラーを発生順に表示し、
  ウィンドウ下部に終了状態、実行時間、通常終了時の終了コードを表示します。
  結果の表示上限は 1 回あたり 1 MiB です。「コピー」で表示内容をコピーできます。
  縦と横の境界線をドラッグすると、各欄の大きさを変更できます。

ファイルと作業状態
  UTF-8 の .py ファイルを開いて保存できます。開いたファイルでは改行形式
  （LF / CRLF）と UTF-8 BOM の有無を引き継ぎます。
  既存ファイルは保存前の編集内容のまま実行できます。相対パスとローカル
  モジュールの基準は .py ファイルのフォルダーです。無題の場合は起動時の
  作業フォルダーが基準になります。
  正常に閉じると、無題のコード、標準入力、時間制限を次回に引き継ぎます。
  名前付きのファイルを開いていた場合は、次回もそのファイルを開きます。
  状態の保存先は %LOCALAPPDATA%\PyDesk\session.txt です。
  PyDesk.exe "C:\work\main.py" のように、起動時にファイルを指定できます。
  Python は現在の Windows ユーザー権限で動作します。

ソースからビルド
  Visual Studio 2022 Build Tools の「C++ によるデスクトップ開発」と
  Windows SDK がある環境で、展開先のフォルダーから実行します。
    build.cmd          アプリを build\PyDesk.exe に生成
    build.cmd test     エディタの変換処理と Python 実行のテスト
    build.cmd ui-test  実際のウィンドウで編集、実行、停止を確認
  外部パッケージの取得は不要です。実行ファイルは x64、CRT は静的リンクです。
